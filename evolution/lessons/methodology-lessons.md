# 通用方法错误与修法

这些条目是对工作方法的整理，不是账号分析结果；不含真实个人案例或原句。

| 容易出错的地方 | 应采取的做法 |
|---|---|
| 把摘要、改写或空文件当逐字语料 | 在统计前标记材料性质并过滤 |
| 看文件名筛主题，漏掉正文相关材料 | 扫描正文，再人工复核相关子集 |
| 只看语气词，忽略每段的作用 | 将表达统计与叙事逻辑分开分析 |
| 不同标点口径混算句长 | 统一切句规则并报告口径 |
| 转写中的自称变体被误认作多人 | 在私有工作区核对来源并归并 |
| 高频写法被直接宣称有效 | 有效果数据时做对照，否则只称观察 |
| 播放量差异被误归因于写法 | 检查发布时间、题材和受众等混淆 |
| 多来源合并遗漏输入 | 用清单与逐批回执核对，验证输出增量 |
| 模板齐全就宣称任务完成 | 用真实输出检查规则是否执行 |
| 一次偶发句式被当成固定招牌 | 在完整覆盖范围内核对频次与语境 |
| 来源账号的经历被写成自己的经历 | 采用调用者的真案例，或讲独立的方法 |
| 没有前作却使用连续性回顾 | 根据调用者真实内容历史决定开场 |
| 多技能副本各自漂移 | 改前比对，改后同步并核验内容 |
| 数字在信源间冲突却任选一版 | 回查一手来源，无法解决时说明不确定 |
| 重写文本被认为自动免除版权义务 | 查具体材料、权利和许可，保留应有声明 |
| 代号被认为等于匿名化 | 检查 ID、拼音、作品线索、原句和组合识别 |
| 公开仓库被用来保存研究原文 | 私有证据与公开方法分目录维护 |
| 清理当前文件就认为历史已清理 | 单独检查旧提交、分支、Fork 与缓存 |
