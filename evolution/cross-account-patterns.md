# 五轴定位与通用方法

本公开文件不维护真实账号映射、原句或账号级统计。下面是待填的分析框架，不是任何个人的画像，也不代表已经验证的普遍规律。

| 诊断轴 | 可以观察什么 | 分析时注意 |
|---|---|---|
| 人称 | 演示自述、直接对话、共同讨论 | 标清统计单位，结合上下文解释 |
| 语气 | 克制、口语、正式、轻松 | 语气可随场景变化，不能只看平均值 |
| 情绪推进 | 共情、挑战观点、解释事实、提供希望 | 区分对事情的描述与对人的评价 |
| 标点与句读 | 口播断句、书面标点、长短句组合 | 切句口径保持一致，转写标点不一定是作者选择 |
| 信任来源 | 演示过程、可核实事实、个人经历、解释与比喻 | 经历不挪用，观点不充当事实 |

## 通用检查

- 区分原始转写、摘要、改写和空文件，先确定材料性质。
- 统计范围与精读范围分别说明，抽样结论不冒充全量。
- 高频特征和效果建议分开记录；没有对照时避免因果宣称。
- 混淆因素、分母、指标单位和适用边界明确。
- 原文、个人经历、独特表述与账号映射保存在私有工作区。
- 公开规则用自写说明和示意例子，并对第三方资料保留应有的许可与来源。
- 规则修改后检查实际产出；多个副本先比对再同步。

完整方法错误清单见 [lessons/methodology-lessons.md](lessons/methodology-lessons.md)。
