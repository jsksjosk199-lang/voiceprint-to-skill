# 【模板】骨相层剖析（core-logic 提取模板）

> **数据边界：** 本文件是空白方法模板。真实账号身份、原文摘录、私人事件及个体统计只能填写在本地私有副本；不要回填到公开仓库。这里的例子是方法示意，不能充当真实个人案例。


> 这是蒸馏任何创作 Skill 时，"骨相层"的提取框架。把对账号精读得到的答案填进去，产出就是这个账号的 `core-logic.md`。
> **骨相是"为什么这么写 / 怎么打动人心"，比皮相（语气词/句首）重要得多。只做皮相 = 仿出来没有灵魂。**

## 一、这个账号到底在"卖"什么？

- 它表面的内容是什么？（讲搞钱 / 讲AI工具 / 讲情感……）
- **它真正让观众觉得"值"的是什么？** 是方法？是情绪？是"这个人本身值得信/值得崇拜"？
- 一句话总结它打动人的核心。

> 提示：很多 IP 型账号，干货只是建立信任的证据，真正卖的是"这个人"（IP 本身）。

## 二、它每条内容在跑什么"情绪曲线"？

观察多条内容，找出共同的"情绪起落"模式。常见模板：
- **先按下去**（让读者觉得"我错了 / 我不懂 / 我渺小 / 我落后"）→ **再拉起来**（给希望 / 给方法 / 给归属"你也可以 / 我带你"）。
- 或者：反常识 → 顿悟 → 行动冲动。
- 或者：共鸣痛点 → 展示别人做到 → 你也行。

把这条曲线的每个阶段写出来，标上"这一阶段在读者心里制造什么"。

## 三、每一段为什么这么写？（逐段心理设计）

| 段落位置 | 表面在做什么 | 在读者心里制造什么 | 目的 |
|---------|------------|------------------|------|
| 开头钩子 | | | 抓住注意力 |
| 破误区 | | | 制造"他有我不知道的" |
| 干货/案例 | | | 建立专业信任 |
| 升维（如有） | | | 从方法到价值观 |
| 自我袒露（如有） | | | 从老师降维成过来人 |
| 金句/信念 | | | 给希望、制造想追随 |
| CTA | | | 转化 |

## 四、它怎么让人"信服 → 崇拜 → 追随"？

- 信服靠什么？（真实案例+具体数字+代价）
- 崇拜靠什么？（敢下判断 / 有观点 / 升维到价值观 / 有故事）
- 追随/付费靠什么？（情感共鸣 + 提供归属 + 显得"拉你一把"）

## 五、它对"目标受众"说了什么"潜台词"？

- 它让读者觉得自己是"谁"？（懂行的？有潜力的？被理解的？）
- 它给读者一个什么样的"自我认同"？

## 六、把它写成 core-logic.md

把上面答案整理成账号的 `core-logic.md`，包含：
- 情绪曲线表（阶段/动作/制造什么/目的）
- 每段为什么这么写
- 怎么让人信服/崇拜/追随
- "灵魂自检"清单（写文案前/后要回答的问题）
