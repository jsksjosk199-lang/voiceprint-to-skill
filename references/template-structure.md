# 【模板】structure 深挖：开头怎么抓人、怎么演进、怎么诱导成交（提取清单）

> **数据边界：** 本文件是空白方法模板。真实账号身份、原文摘录、私人事件及个体统计只能填写在本地私有副本；不要回填到公开仓库。这里的例子是方法示意，不能充当真实个人案例。


> 蒸馏时，光说"要挖骨相"不够。本模板给你**可执行的检查清单**——精读语料时逐项对照，把答案填进产出 Skill 的 `structure-anatomy.md`。
> 它回答三件事：**①开头怎么在 3 秒内抓住人？②从开头到结尾怎么一步步演进、不让人划走？③怎么一步步诱导读者关注/成交？**

---

## 一、开头抓人（打开语料，逐条精读开头 1~3 行）

**第一步**：列出这个账号实际用了哪几种开头钩子（对照通用类型库勾选）：
- [ ] 现象钩（"大家有没有发现……"）
- [ ] 近期见闻钩（"我前几天/昨天……"）
- [ ] 人物案例钩（"有个[人]做了[事]赚了[数字]"）
- [ ] 反常识/反差直给（"一个[普通物]卖[天价]，凭什么"）
- [ ] 靶子反驳（"现在很多人说……其实……"）
- [ ] 扎心提问（"我先问你一个扎心的问题"）
- [ ] 选择题/二选一（"两个选择……90%人选错"）
- [ ] 极端假设/预测（"如果我告诉你……你信吗"）
- [ ] 成果前置（"我用X做了Y省了Z"+录屏）
- [ ] 身份/权威数字（"我创业X年/做了X个"）

**第二步**：**每个钩子配 1~2 条原句摘录**，并在旁边标"这类钩子适合什么选题 / 为什么抓人"。

**第三步**：判断哪种是它的"首选/标志性"钩子（出现最频繁）。**注意：别把一个惊艳但只出现 1 次的钩子当首选**（可能以偏概全）——用频次说话。

**第四步（关键）**：确认"真正的开头钩子"和"自我介绍"是分开的。很多账号第 4~6 行才是"大家好我是 XX"，**真正的钩子在前 3 行**。别把自我介绍当钩子。

---

## 二、从开头到结尾怎么演进？（骨架深挖）

打开几篇不同题材的内容，标出每篇的段落演进，然后归纳共同的"骨架"。

**通用演进骨架**（供对照，看它用到哪些）：
```
钩子(抓人)
  → 破误区/立观点(让你觉得"我可能错了/原来是这样")
  → 给方法/拆干货(案例+数字，证明他真懂)
  → 升维(拔高到价值观/人生，让人崇拜)
  → 自我袒露/立人设(讲自己的坑/至暗/为什么做这个)
  → 金句收束(一句能截图的话)
  → 软CTA(关注/私域/成交)
```

**要标出的重点**：
1. 它的骨架顺序是什么样的？（上面每段都可能出现，也可能跳步）
2. **哪一段写得最长/最用力？**（那就是它重点下功夫的地方）
3. **不同题材骨架差异**？（干货清单类 vs 情感故事类 vs 观点类，可能不同——分别标）
4. 有没有"固定转场话术"？（如"接下来我把门窗关好"式的悬念转折、"多说一句哈"的插叙）——这些是口风 + 节奏资产。

## 三、怎么诱导成交/关注？（成交设计深挖）

精读它**结尾 + 视频中间散布的引导**，回答：

### 3.1 它结尾的 CTA 漏斗是几层？各层话术原句？
| 层 | 动作 | 原句 |
|----|------|------|
| 1 关注/三连 | | |
| 2 公众号/加微信领资料 | 资料名具体吗？ | |
| 3 免费诊断/咨询 | | |
| 4 付费成交 | | |

### 3.2 成交前的心理铺垫话术（挖原句）
- 制造稀缺/名额有限？______
- 身份认同（"给想XX的人"）？______
- 价值前置（先给再谈）？______
- 不硬推、甚至先拒绝？______
- 评论区互动（"你最想试哪个"）？______

### 3.3 免费红线（产出用于获客时铁律）
- 免费 = 诊断 / 看方向 / 领资料 / 评估值不值
- **开发 / 交付 / 成交本身 = 必须收费**
- 话术要让"免费诊断"和"付费成交"边界清晰，别让人误以为服务也免费

### 3.4 它的成交靠的是"工具/方法"还是"信任/人设"？
很多 IP 型账号成交不靠功能堆砌，靠前面整条内容攒下的信任——读者是"因为信这个人"才买。标出这个账号主要靠哪种。

---

## 四、产出：写成 structure-anatomy.md

把上面的答案整理成该账号的 `structure-anatomy.md`，包含：
- 开头钩子库（类型 + 原句 + 适用选题）
- 演进骨架（含不同题材的差异）
- 固定转场/口风资产
- 成交漏斗 + 铺垫话术 + 免费红线
- 供写作时逐段对照

> 此模板与 `template-core-logic.md`（骨相/灵魂）配合：core-logic 讲"为什么这么写、怎么打动人心"，本模板讲"具体手艺长什么样、怎么从语料抓出来"。两个都做完，产出 Skill 的手艺层才完整。
