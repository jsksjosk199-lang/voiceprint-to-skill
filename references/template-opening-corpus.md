# 【模板】开头与结尾的私有证据库

本文件为空白流程，不包含任何人物原句。完整语料与摘录只存入本地私有工作区；公共 references 不保存原文库。

## 提取方法

1. 核对材料是逐字稿、改写还是摘要；确认允许处理的范围。
2. 逐文件编号，通过实际结构锚点定位开场与结束，不用固定行号代替判断。
3. 在私有工作区记录每条材料的来源、版本、开场结构摘要、结尾结构摘要和本地证据位置。
4. 分类未确定时列出例外，核查后重新统计。说明统计分母与覆盖范围。
5. 对拟公开文件只保留结构说明与自写示例，删除原句、真实标题、账号 ID、作品链接和身份映射。
