- 在修改过的文件中显著说明发生了修改，例如注明修改者、日期与改动范围；只更新总日志不能替代必要的文件修改说明。
- 可以免费或收费发布、封装和交付；不因商用向本项目作者付费或分成。
- 无需把你的全部新增或可分离作品改成 Apache-2.0；其许可须与所包含部分的既有许可兼容。

## 用工具制作独立的新 Skill

仅使用工具不自动使新 Skill 成为本项目的衍生作品。未复制本项目内容且未另行加入协议时，工具来源标注是建议，不是 Apache-2.0 的强制要求。

建议随新 Skill 提供如下来源段；默认可以生成这段供作者核对，不能把建议说成所有使用者必须接受的条件：

```text
制作工具：Voiceprint to Skill（作者：jsksjosk199-lang / ysy985221）
项目来源：https://github.com/jsksjosk199-lang/voiceprint-to-skill
工具许可：Apache-2.0；本 Skill 的作者与许可另行说明。
该标注不表示原项目作者为本 Skill 背书。
```

若使用者已与作者明确同意 [自愿来源标注约定](../USE-AGREEMENT.md)，按双方约定保留工具来源段；依据是合同。不要从下载、使用或客户接收交付推定同意。

若新 Skill 实际包含本项目或第三方受保护内容，则另按包含内容及相应许可履行义务；不能因为将其命名为“独立产物”就略过判断。来源标注也不代替语料授权与隐私检查。
