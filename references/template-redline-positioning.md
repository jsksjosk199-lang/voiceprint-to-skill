# 【模板】红线层剖析（case-authenticity / positioning 提取模板）

> **数据边界：** 本文件是空白方法模板。真实账号身份、原文摘录、私人事件及个体统计只能填写在本地私有副本；不要回填到公开仓库。这里的例子是方法示意，不能充当真实个人案例。


> 蒸馏任何创作 Skill 时，先判断"调用者是不是账号本人"。绝大多数情况调用者是"借风格做自己内容"的另一人。此时必须做红线与定位分析。

## 一、调用者是谁？（先定这个，否则文案里"我"站不住）

- 调用者 IP 名：______（不能把账号本人 IP 名安上去）
- 真实身份：______（在学？创业者？某行业从业者？）
- 真实做过什么：______（哪些是真经历，能讲？）
- 有哪些"可讲的真案例"：______（哪怕很小，如自己做过一个 AI 排版 Skill）

## 二、账号本人的"人设经历"清单（红线：不可挪用）

把账号本人反复讲、属于他个人的人设资产列出来：
- 如：连续创业 N 年 / 破产亏几百万 / 留学断供 / 赋能上千商家 / 个人自称 / 他的至暗时刻……
- **这些都不能安在调用者头上。** 若调用者没有对应经历，文案里就不能讲成"我"。

## 三、案例的三个来源（写作时只能从这里取）

1. **调用者亲身经历**（讲"我"）——必须真实。
2. **转述他人**（讲"我有个学员/朋友/客户说……"）——必须有出处，用"他说/跟我讲"保持转述，不用"我做了"代替"他做了"。
3. **泛指/观察**（"我观察到 / 很多人 / 有些人"）——诚实观察不算捏造。

**没有真案例的替代**：用"我观察到 / 很多人 / 回归方法本身讲透"，**绝不硬编一个有具体身份+数字的假案例**。

## 四、案例真实性自检（每篇必过）

- [ ] 案例主角是谁？我亲身 / 我转述 / 我观察？——必须明确
- [ ] 我讲"我"的经历，真是我经历的吗？（不是 → 改渠道 2 或换掉）
- [ ] 我讲别人的案例，有交代来源（"有个学员说"）吗？
- [ ] 有没有把账号本人的"破产/创业N年/赋能上千"安在自己头上？
- [ ] 数字是我真实知道/可信转述的吗？会不会一追问就露馅？

## 五、定位层模板（若是获客/卖货场景）

- 调用者卖什么：______（如 AI Skill 开发服务 / 课程 / 咨询）
- 目标客户：______（如企业老板/个体户）
- 客单：______（几千到几万？）
- 结尾往哪引（CTA 漏斗）：关注 → 公众号/加微信领资料 → 免费诊断/咨询 → 付费成交
- **免费红线**：免费只用于"诊断/看方向/评估值不值得"；**开发/交付/成交本身必须收费**，别把服务说成免费。
- 内容主题库：围绕获客的选题（认知类/方法类/过程类/避坑类），每个能绕回"找我做"。

## 六、产出

把二~五整理成该 skill 的 `case-authenticity.md`（红线）+ `positioning.md`（定位）。
